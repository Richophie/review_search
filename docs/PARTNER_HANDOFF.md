# 체험모아 파트너 개발 인계 문서

## 목적
기존 체험단 통합검색(`/`)을 손대지 않고 같은 TanStack Start 앱에 신규 파트너 서비스(`/partner`)를 추가한다.

## Git 및 범위
- Repo: `Richophie/review_search`
- 작업 브랜치: `feature/partner-platform-v1`
- 신규 페이지: `src/routes/partner/index.tsx`
- 신규 페이지는 현재 **안내·기획 화면**이며 회원가입이나 신청이 된다고 표현하지 않는다.
- 현재 메인 검색, 수집, DB 테이블, 라우팅 헤더는 변경하지 않았다.

## 확정 제품 원칙
- 외부 원본 공고는 기존 검색·수집 시스템 유지
- 자체 캠페인 별도 테이블(`owned_campaigns`) 및 별도 권한 정책
- 광고주와 크리에이터의 기본 모집/신청은 무료
- 선정, 일정, 후기 제출, 광고 표시 체크, 양측 대시보드 구현 목표
- 단일 GitHub 저장소, 동일 배포 앱의 별도 경로

## 다음 개발 순서
1. 현재 저장소 DB/인증/배포 흐름을 조사하고 회귀 테스트 작성
2. Supabase Auth + profile / organization / creator_channels, RLS 도입
3. 캠페인 생성과 관리자 승인, 이미지 업로드
4. 크리에이터 신청/선정과 정원 초과 방지
5. 일정/후기 제출/광고 표기 확인
6. 양측 대시보드
7. 별도 검증 후 필요 시 기존 통합검색에 자체 캠페인 통합

## 보안과 운영
- 본인만 데이터 접근 가능, 광고주 조직별 권한 경계 검증
- 운영 DB 무단 마이그레이션 금지, 서비스 롤 키 노출 금지
- 신청 정보와 개인 일정은 공개 페이지에 노출하지 않음
- 외부 공고를 자체 모집으로 오인하게 만들지 않음
- 공개 검색은 로그인 없이 그대로 유지

## 코덱스 인계
이 브랜치와 본 문서 및 GitHub PR diff를 읽고 계속 개발하면 된다.
각 단계는 구현과 테스트를 별도로 보고하고, 실제 연결되지 않은 기능을 완료로 표시하지 않는다.
