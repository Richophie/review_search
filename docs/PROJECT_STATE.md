## 1. 제품 목표와 확정 범위
- 국내 누구나 이용하는 **체험단 공고 통합 검색** 서비스. 특정 지역(검단)에 한정하지 않음.
- 인플렉서와 리뷰로거의 *기능*을 벤치마킹하되 화면/코드/데이터를 그대로 복제하지 않음.
- 1차: 검색, 키워드/지역, 리뷰 매체, 캠페인 유형, 포인트 지급, 오늘 마감, 경쟁률 낮은 공고, 원본 바로가기.
- 정렬: 최신순, 마감일 임박순, 경쟁률 낮은순, 잔여 모집 인원 많은순. **제공금액 높은순은 제외**.
- 매체: 블로그 포스팅, 인스타 포스팅, 유튜브 포스팅, 블로그 클립, 인스타 릴스, 유튜브 쇼츠, 틱톡, 스레드. **쇼핑몰 제외**.
- 유형: 방문형/배송형/기자단. 포인트 지급: 전체/O/X(미공개는 임의로 O/X 분류하지 않음).
- 회원가입, 찜/신청/선정/리뷰 관리, 지도 기능은 1차 범위 **제외 또는 추후 검토**.
- 해외 체험단(베트남 등) 추가는 중장기 확장 계획.
- 디자인: 기존 구축 UI가 마음에 들어 **기능 안정화 전까지 큰 수정은 원하지 않음**. 카드 사진 깨짐과 카드 품질은 예외적으로 개선 요청.
- **가짜 공고 금지**, 마감/중복/출처 검사, 무료 중심 운영.

## 3. 수집기 관련 기존 결정
- 플랫폼 수 자체보다 **원본 모집 중 공고 대비 수집률**을 측정.
- 가능한 경우 공개 페이지를 깊이 순회하되 호출 속도·접근 제한·이용약관 준수.
- 마감일 파싱 실패만으로 모집 중임이 확인된 공고를 무조건 버리지 않음. 대신 마감일 미확인 공고는 오늘 마감/마감 임박순에 넣지 않음.
- 경쟁률 = 신청자 수 / 모집 인원. 원본 수치가 없으면 경쟁률 미공개. 실제 저경쟁 필터/정렬의 포함 규칙을 소스에서 확인.
- 원본 링크, 모집 상태, 중복, 마감 여부 점검. 목록 수와 실제 유효 공고 수 구별.
- 제한된 소스는 무단 우회하지 않고 허용된 데이터 제공/제휴 경로 검토.
