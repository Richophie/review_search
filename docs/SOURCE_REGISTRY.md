## 검증 기준

- **수집기만 등록**: 코드가 실행 경로에 있으나 저장된 공고 0건. 연결 완료로 표시하지 않음.
- **후보**: 실제 추출·자동 업데이트·수집 허용 여부의 검증을 통과하지 못함.
