# 매체 분류 및 신규 소스 우선순위 (2026-10-10)

## 필수 분류 정책
- 같은 업체/혜택이라도 **원본 캠페인 ID 또는 매체가 다르면 서로 다른 모집 공고**로 보존한다.
- 현재 `channels`는 한글 라벨 배열이다. 데이터 호환성을 유지하면서 차기 마이그레이션에서는 아래 8개 **세분화된 canonical 채널 코드**를 사용한다.
  - `naver_blog` — 네이버 블로그 포스팅
  - `naver_clip` — 네이버 클립
  - `instagram_post` — 인스타그램 게시물(피드)
  - `instagram_reels` — 인스타그램 릴스
  - `youtube_video` — 유튜브 일반 영상
  - `youtube_shorts` — 유튜브 쇼츠
  - `tiktok` — 틱톡
  - `threads` — 스레드
- **인스타 피드/릴스, 유튜브 영상/쇼츠를 합쳐서는 안 됨.**
- 원본이 단순히 '인스타그램'이라고만 표시하면 `instagram_post`로 단정하지 말고 `instagram_unknown` 또는 미분류로 둔다. '유튜브' 역시 세부 구분이 없으면 미분류 유지.
- 매체가 표기되지 않은 공고는 블로그로 추정하지 않는다. 일부 채널만 확인된 공고는 확인된 것만 기록.
- 다중 매체 의무면 하나의 원본 공고 ID에 여러 채널을 부여한다. 각각 별도 신청하는 공고라면 원본 ID별로 독립 보존.
- 외부 사이트의 **모집 중 여부·마감·원본 URL**은 확인된 정보만 기록. 모집인원과 신청자가 없으면 경쟁률도 없음.
- 기존 사용자 검색과 URL 파라미터 `ch` 호환성을 고려해 `channels_v2` 병행 저장 후 실제 데이터를 재수집하여 UI 필터를 전환한다. 이미 수집된 모호한 과거 값을 세부 카테고리로 일괄 변환하지 말 것.

## 신규 소스 조사 우선순위
1. **리뷰노트** — 대형 맛집·뷰티 공고 후보. 공식 공개 목록, 원본 링크, robots.txt, 조건 확인.
2. **강남맛집** — 전국 방문형 후보. '강남' 지역만으로 한정하지 말고 전국 목록을 확인.
3. **레뷰(REVU)** — 대형 SNS/숏폼 후보. 공식 모집 공고 경로, 페이지 접근·허용 조건 확인. 광고주용 비즈니스 페이지는 공고 소스가 아님.
4. **데일리뷰·스타일씨·모두모여체험단·똑똑리워드** — 기존 연결 상태와 공개 범위 비교해 우선순위 조정.
5. 리뷰플레이스, 리뷰진, 후기업, 위유체험단, 오마이블로그, 리얼리뷰 등.

이 목록은 **연동 완료 목록이 아니다.** 외부 집계 사이트의 숫자는 공식 전체 모집 건수와 다를 수 있고, 우리 수집 결과로 취급하면 안 된다.

## 소스 도입 완료 기준
1. 공식 도메인 식별
2. 공개 접근/robots.txt/이용약관 확인, 계정·차단 우회 금지
3. 공개 카드 최소 몇 건의 제목·URL·매체·모집상태·마감 추출 검증
4. 중복 ID/URL과 실제 신청 가능 여부 검사
5. 수집기 코드 + 검증 + 소스 허용 목록 + 검색 플랫폼 이름 연계
6. 정기 수집 성공 후 실제 등록 건수/미분류율 보고
7. 변경을 모아 Vercel 단일 배포 (한도 소진 주의)
